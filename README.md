# Teyitli
Early product demo for a brand-impersonation, phishing-detection and verified-link platform.

## Demo
The prototype contains:
- URL/domain risk analysis in the browser
- lookalike / typo / Punycode signals
- a simulated brand-monitoring radar
- a simulated Verified Origin Proof flow

The current GitHub Pages build is intentionally static. DNS/WHOIS/TLS reputation, web crawling, visual similarity, credential-form detection and takedown automation are roadmap items.

All brands shown inside the demo are fictional.
